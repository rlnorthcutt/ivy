Questions people ask

Does it need a build step?

No. Link the stylesheet and write HTML. If you want only the core, link only the core file.

How do I override a default?

Write ordinary CSS. Because both layers are inside @layer, any unlayered rule of yours takes precedence regardless of specificity.

/* wins, no !important needed */
button { border-radius: 999px; }
How do I change the palette?

Reassign the light and dark palette variables on :root. The applied tokens read from them, so both themes update together.

What about layout?

Deliberately out of scope. Placement is left to a companion sheet like Lattice, or to your own grid.
