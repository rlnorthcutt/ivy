Ivy CSS in practice

Examples

The element and component references show what each piece looks like on its own. These pages show what happens when you put the pieces together — three full layouts, built only with semantic HTML, the core defaults, and a handful of data-* attributes from the extra layer.

Landing page

A marketing page — hero, feature cards, a comparison table, an FAQ and a signup form. The case that puts the button, card and callout variants to work.

Article

Long-form reading at the library's default measure and line height — headings, lists, a blockquote, a figure, a table and a code sample, in the order a real article uses them.

App screen

A dense records screen — filters, a data table, a detail panel and a settings form. The case where a document-first stylesheet has to behave like application chrome.

Reading these pages

Nothing on any of the three pages uses a layout framework. Structure comes from ordinary elements — section, article, table, form — and the only classes in play are the small set of utilities and components documented on the extra demo page.
